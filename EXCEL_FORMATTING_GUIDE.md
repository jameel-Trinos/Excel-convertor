## Critical Formatting Rules

### ✓ DO THIS (Recommended Approach)

```python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side
from openpyxl.utils import get_column_letter

# 1. Set FIXED column widths (NOT auto-fit)
for col in range(1, num_columns + 1):
    col_letter = get_column_letter(col)
    worksheet.column_dimensions[col_letter].width = 16  # 15-20 recommended

# 2. Set proper row heights
worksheet.row_dimensions[header_row].height = 70  # Header (with wrap_text)
for row in range(data_start, data_end + 1):
    worksheet.row_dimensions[row].height = 18  # Data rows

# 3. Use wrap_text=True ONLY for headers
header_alignment = Alignment(horizontal='center', vertical='center', wrap_text=True)
data_alignment = Alignment(horizontal='center', vertical='center', wrap_text=False)

# 4. Freeze header row
worksheet.freeze_panes = 'A7'  # Or whatever row is after headers
```

### ✗ AVOID THIS (Causes Collapsed Appearance)

```python
# ✗ DON'T use auto-fit alone (unreliable)
for column in worksheet.columns:
    worksheet.column_dimensions[column[0].column_letter].width = len(str(column[0].value))

# ✗ DON'T leave row heights at default (looks squished)
# (No row height settings)

# ✗ DON'T skip wrap_text on headers (text gets cut off)
alignment = Alignment(horizontal='center', vertical='center')  # Missing wrap_text=True
```

## Column Width Management

### Fixed Width Method (RECOMMENDED)

**Why**: Auto-fit is unreliable and can make columns too narrow or too wide.

```python
# Method 1: Same width for all columns
from openpyxl.utils import get_column_letter

for col in range(1, worksheet.max_column + 1):
    col_letter = get_column_letter(col)
    worksheet.column_dimensions[col_letter].width = 16

# Method 2: Custom width per column
column_widths = {
    1: 15,  # Polling Station
    2: 18,  # Candidate 1
    3: 18,  # Candidate 2
    # ... etc
}

for col, width in column_widths.items():
    col_letter = get_column_letter(col)
    worksheet.column_dimensions[col_letter].width = width
```

### Recommended Widths
- **Short text** (IDs, codes): 10-12 characters
- **Standard data** (names, numbers): 15-18 characters
- **Long text** (descriptions): 20-25 characters
- **Very long text**: 30+ characters

## Row Height Management

### Critical Heights

```python
# Title rows (merged, large font)
worksheet.row_dimensions[1].height = 25

# Header row (with wrapped text)
worksheet.row_dimensions[6].height = 70  # Increase to 80-90 if headers are very long

# Data rows (standard)
for row in range(7, last_row + 1):
    worksheet.row_dimensions[row].height = 18  # Gives breathing room

# Total row (bold)
worksheet.row_dimensions[total_row].height = 20
```

### Why These Heights Matter
- **Default height (15)**: Looks squished and unprofessional
- **18px**: Perfect for standard data with borders
- **70px**: Accommodates wrapped header text (2-3 lines)
- **90px**: For very long wrapped headers (4+ lines)

## Cell Formatting

### Header Cells (Dark Blue with White Text)

```python
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

# Colors
HEADER_BG = "4472C4"  # Dark blue
HEADER_FG = "FFFFFF"  # White

# Font
header_font = Font(bold=True, size=10, color=HEADER_FG)

# Fill
header_fill = PatternFill(start_color=HEADER_BG, end_color=HEADER_BG, fill_type='solid')

# Alignment (CRITICAL: wrap_text=True)
header_alignment = Alignment(horizontal='center', vertical='center', wrap_text=True)

# Border
thin_border = Border(
    left=Side(style='thin', color='000000'),
    right=Side(style='thin', color='000000'),
    top=Side(style='thin', color='000000'),
    bottom=Side(style='thin', color='000000')
)

# Apply to header cell
cell.font = header_font
cell.fill = header_fill
cell.alignment = header_alignment
cell.border = thin_border
```

### Data Cells (White with Black Text)

```python
# Font
data_font = Font(bold=False, size=10, color='000000')

# Alignment (NO wrap_text for data)
data_alignment = Alignment(horizontal='center', vertical='center', wrap_text=False)

# Border
data_border = Border(
    left=Side(style='thin', color='000000'),
    right=Side(style='thin', color='000000'),
    top=Side(style='thin', color='000000'),
    bottom=Side(style='thin', color='000000')
)

# Apply to data cell
cell.font = data_font
cell.alignment = data_alignment
cell.border = data_border
```

### Title Cells (Merged, Centered, Bold)

```python
# Merge cells across all columns
worksheet.merge_cells(f'A1:{get_column_letter(num_columns)}1')

# Format merged cell
cell = worksheet['A1']
cell.value = 'FORM 20 - FINAL RESULT SHEET'
cell.font = Font(bold=True, size=14)
cell.alignment = Alignment(horizontal='center', vertical='center')
cell.fill = PatternFill(start_color='D9E1F2', end_color='D9E1F2', fill_type='solid')
```

## Formula Best Practices

### SUM Formulas (Row Totals)

```python
# For each data row, add total in last column
total_col = num_columns
for row in range(data_start_row, data_end_row + 1):
    cell = worksheet.cell(row=row, column=total_col)
    # Sum from column B to second-to-last column
    cell.value = f"=SUM(B{row}:{get_column_letter(total_col - 1)}{row})"
    cell.number_format = "#,##0"
```

### SUM Formulas (Column Totals)

```python
# Total row at bottom
total_row = data_end_row + 1
worksheet.cell(total_row, 1).value = "TOTAL"

for col in range(2, num_columns + 1):
    cell = worksheet.cell(total_row, col)
    col_letter = get_column_letter(col)
    cell.value = f"=SUM({col_letter}{data_start_row}:{col_letter}{data_end_row})"
    cell.number_format = "#,##0"
```

### Common Formula Errors
- **#REF!**: Invalid cell reference (wrong range)
- **#DIV/0!**: Division by zero
- **#NAME?**: Unrecognized function name
- **#VALUE!**: Wrong type of argument

## Common Mistakes to Avoid

### ❌ Mistake 1: Using Auto-Fit Only

```python
# ❌ BAD: Auto-fit can make columns too narrow
for column in worksheet.columns:
    max_length = max(len(str(cell.value)) for cell in column)
    worksheet.column_dimensions[column[0].column_letter].width = max_length
```

**Why it fails**: Auto-fit doesn't account for padding, borders, or font rendering differences.

**✓ Solution**: Use fixed widths (15-20 characters).

---

### ❌ Mistake 2: Forgetting Row Heights

```python
# ❌ BAD: No row height settings
# (Cells use default 15px height, looks squished)
```

**✓ Solution**: Explicitly set header to 70px and data rows to 18px.

---

### ❌ Mistake 3: No wrap_text on Headers

```python
# ❌ BAD: Headers get cut off
alignment = Alignment(horizontal='center', vertical='center')  # Missing wrap_text=True
```

**✓ Solution**: Always use `wrap_text=True` for headers.

---

### ❌ Mistake 4: Wrong Formula Ranges

```python
# ❌ BAD: Formula references wrong columns
cell.value = f"=SUM(A{row}:Z{row})"  # Hardcoded range

# ✓ GOOD: Calculate range dynamically
last_col = get_column_letter(num_columns - 1)
cell.value = f"=SUM(B{row}:{last_col}{row})"
```

---

### ❌ Mistake 5: Not Merging Title Cells

```python
# ❌ BAD: Title only in column A
worksheet['A1'] = 'FORM 20 - FINAL RESULT SHEET'

# ✓ GOOD: Merge across all columns
worksheet.merge_cells(f'A1:{get_column_letter(num_columns)}1')
worksheet['A1'] = 'FORM 20 - FINAL RESULT SHEET'
```

---

### ❌ Mistake 6: Skipping Freeze Panes

```python
# ❌ BAD: No freeze panes (headers scroll out of view)

# ✓ GOOD: Freeze header row
worksheet.freeze_panes = 'A7'  # Freeze everything above row 7
```

## Summary

**The Golden Rules**:
1. **Fixed column widths** (15-20 chars) > Auto-fit
2. **Set row heights** (header: 70px, data: 18px)
